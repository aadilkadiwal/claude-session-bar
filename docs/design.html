Session Bar

A small macOS menu bar app for Claude Code. It shows how much of your usage limit is left, lists your sessions as they start and stop, turns phone access on or off for a session, and starts new sessions without opening a terminal first.

Session names and folders below are real ones from your Mac. Usage percentages are example values.

Under the hood

Where the information comes from

Session Bar has no server and no login of its own. It reads files Claude Code already writes on your Mac and runs the normal claude command for every action.

Flows

What happens, step by step

Every button in the mockups above, as the sequence of things the app does.

Install (one command)

You paste one line into Terminal

  1. curl -fsSL https://raw.githubusercontent.com/<you>/session-bar/main/install.sh | bash
  2. The script downloads the latest release from GitHub and copies it into /Applications.
  3. It adds one line to your status line script so usage gets saved to ~/.claude/usage.json. Your existing status line stays as it is.
  4. It opens Session Bar and turns on "Open at login".

Usage rings update

Automatic, whenever any session is active

  1. Claude Code refreshes the status line and passes along your 5-hour and weekly percentages.
  2. The added line saves them to usage.json.
  3. Session Bar sees the file change and redraws the rings and the menu bar number.
  4. If no session has run for a while, the rings show "updated 3h ago" so you know the number is old.

Session list stays live

Automatic

  1. You start claude anywhere, in any terminal or in the background.
  2. Claude Code writes a file for it in ~/.claude/sessions/.
  3. Session Bar sees the new file straight away and puts the session at the top of "Running now".
  4. When the session closes, its file disappears and the row moves to "Recent · closed".

Phone button on a closed or background session

Click the grey phone icon

  1. Runs claude --bg --resume <id> --remote-control in that folder.
  2. The session starts in the background. No window opens.
  3. The phone icon turns blue. Open the Claude app on your phone and the session is listed.

Phone button on a session open in Terminal

Click the grey phone icon

  1. Shows the "Move to your phone?" pop-up.
  2. On confirm, the app closes the session in its Terminal tab cleanly, the same as pressing Ctrl+C twice.
  3. It reopens the session in the background with phone access on, using the same command as above.
  4. The row moves under the background sessions with a blue phone icon.

Stop (also turns phone access off)

Click ■ on a running session

  1. Asks first only if the session is working or waiting on you.
  2. Background session: runs claude stop <id>. Terminal session: sends it a clean close signal.
  3. Claude Code shuts down and disconnects remote control, so the session leaves your phone list.
  4. The row moves to "Recent · closed". The history is kept.

New session

Click "＋ New session…"

  1. Pick a recent folder chip or browse to a folder, and add a name if you want.
  2. Start for phone: runs claude --bg --remote-control -n <name> in that folder. Nothing opens on the Mac.
  3. Open in Terminal: opens a new Terminal window running cd <folder> && claude -n <name>.
  4. The session appears at the top of the list within a second.

Click a session row

Click the name of any row

  1. Running in Terminal: brings that Terminal tab to the front.
  2. Background session: opens a Terminal window running claude attach <id>.
  3. Closed session: opens Terminal with claude --resume <id> in its folder.

Delete sessions

Details → select rows → Delete selected

  1. Only closed sessions can be selected. Running ones must be stopped first.
  2. A confirmation shows how many sessions and how many MB will be deleted.
  3. The session files go to the macOS Trash, so you can still restore them until you empty it.
  4. Note: this frees space on your Mac. It does not remove old entries from claude.ai's list.

Change how long history is kept

Settings → Keep history for

  1. Change the number of days, for example from 30 to 180.
  2. The app writes cleanupPeriodDays into ~/.claude/settings.json and leaves your other settings untouched.
  3. From then on, Claude Code deletes sessions older than that on its own. You never need a "delete old sessions" button.

Clean up now

Settings → Choose date…

  1. Pick a date. The default is 6 months ago.
  2. The app shows how many closed sessions are older than that date and their total size.
  3. On confirm, they go to the Trash, the same as Delete selected.
Before building

What still needs a quick test

Everything else is confirmed on your Mac with Claude Code 2.1.288.

TEST

Does a session started with claude --bg --remote-control show up in the Claude phone app? The design for "Start for phone" and the phone button depends on it.

TEST

Does stopping a session (claude stop or a clean close) remove it from the phone list? This is your original problem, so it matters most.

TEST

Can the app bring a specific Terminal tab to the front? Terminal and iTerm allow it through AppleScript. Other terminals (Warp, Ghostty) might not. If one doesn't, clicking the row opens a new window instead.

CONFIRMED

Live session list with name, folder, ID, busy/idle state and phone on/off (~/.claude/sessions/*.json). Background sessions via claude agents --json. Usage percentages and reset times in the status line data. History cleanup via cleanupPeriodDays.
